Updates and support

Version {{ version }}. The agent checks for a new release every hour and shows a banner. Updating pauses the agent, saves a backup, installs the release and restarts. If the new version does not start, the old version and your database are put back.

Backups

A copy of the database (settings, connections, plans) is saved before every update and every clean-up run. The last 10 are kept in the backups folder of this instance's data folder.
