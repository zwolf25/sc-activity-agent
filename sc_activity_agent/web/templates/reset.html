Factory reset

This cannot be undone from the app. It deletes everything you set up and everything the agent tracks.
{% if busy %}

{{ busy }} Reset is unavailable until then.

{% endif %}

What is deleted

  • {{ counts.connections }} connection(s) and {{ counts.users }} user(s), including saved Client IDs, secrets and passwords
  • {{ counts.locations }} location(s) and their settings
  • {{ counts.wos }} tracked work order(s) and {{ counts.steps }} planned step(s). Pending steps never run.
  • The audit log ({{ counts.log }} row(s)), the error lists and alert history
  • All settings: behavior, caps, dashboard choice, Telegram token, schedules, caches

What is kept

  • The environment ({{ env|upper }}), the port and the secret key chosen at install
  • The backups folder, with a new backup of the current database made right before the reset

What is not touched

Work orders already created in ServiceChannel stay there. After a reset the agent forgets them and cannot cancel them. If you want them cancelled, run Clean-up first.

To undo a reset, stop the agent and run agent backup <name> with the backup named in the confirmation message.
